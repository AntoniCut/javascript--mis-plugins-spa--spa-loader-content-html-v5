Validación de formulario en el servidor

PHP se ejecuta en el servidor: PHP-FPM en producción y php-cgi en el servidor de desarrollo. El navegador solo envía el formulario y muestra la respuesta.

El endpoint app/services/php/validate.php no confía en el navegador: recibe JSON, valida nombre, correo y mensaje, y devuelve los errores por campo junto con los datos ya normalizados. Todo el contrato es JSON con códigos HTTP.

Qué aporta este endpoint

El servidor decide

Las reglas viven en PHP: el navegador puede enviar cualquier cosa y el servidor responde con el error exacto de cada campo.

Contrato JSON + códigos HTTP

200 en éxito, 400 con JSON inválido, 405 para otro método y 422 con errores por campo. La respuesta incluye serverTime y el runtime.

Sin base de datos ni dependencias

No usa MySQL, .env ni Composer: es un único archivo compatible con PHP-FPM, php-cgi y cualquier hosting con PHP.
