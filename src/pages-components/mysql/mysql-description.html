Consultas sobre javascript_mis_plugins_spa

MySQL guarda la tabla stacks de este prototipo. El contenedor Docker publica el puerto 3308 para no ocupar el MySQL del curso de EscuelaIT.

El navegador no se conecta a MySQL. El formulario envía la sentencia a app/services/mysql/query.php, que la ejecuta con el usuario javascript_user y devuelve las filas en JSON.

Qué puedes consultar

Tabla stacks

Siete páginas del stack: slug, título, ruta y orden.

Solo lectura

SELECT, SHOW, DESCRIBE y EXPLAIN. Una sentencia por envío.

Tope de filas

La respuesta muestra como máximo 200 filas.
